# Instamart Next Product Prediction Notebooks

This repository contains the following notebooks:

1. **1. Data_Analysis.ipynb**  
   Introduces the project, dataset scope, and core analysis objectives for next-product prediction.

2. **2. Exploratory_Data_Analysis.ipynb**  
   Explores ordering and reordering behavior across aisles, products, and customer activity patterns.

3. **3. Customer_Segementation.ipynb**  
   Performs customer segmentation using PCA and K-Means clustering to group similar purchasing behaviors.

4. **4. Market_Basket_Analysis.ipynb**  
   Applies market basket analysis (Apriori/association rules) to discover product co-purchase relationships.

5. **5. Feature Extraction.ipynb**  
   Builds and prepares model-ready features from transactional and user-product interaction data.

6. **6. ANN Model.ipynb**  
   Trains and evaluates an Artificial Neural Network model for product reorder prediction.

7. **7. XGBoost Model.ipynb**  
   Trains and evaluates an XGBoost model for product reorder prediction and comparison with other approaches.
